
# HomeCash - Regras do Claude

## Economia de tokens
- Seja direto e evite explicações longas.
- Não repita informações já fornecidas.
- Não leia arquivos sem necessidade.
- Analise somente arquivos relacionados à tarefa.
- Não faça pesquisas externas sem necessidade.
- Não apresente várias soluções quando uma for suficiente.
- Evite refatorações não solicitadas.
- Não reescreva arquivos inteiros se uma alteração pequena resolver.
- Não execute comandos repetidamente.
- Não faça resumos extensos após cada alteração.

## Desenvolvimento
- Identifique a causa antes de corrigir.
- Altere o mínimo possível de arquivos.
- Preserve funcionalidades existentes.
- Não altere o banco sem autorização.
- Execute testes relevantes e build quando necessário.
- Não faça commit ou push sem autorização.

## Resposta
Informe somente:
1. Problema identificado.
2. Solução aplicada.
3. Arquivos alterados.
4. Resultado dos testes.
